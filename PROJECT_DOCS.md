# Project Documentation

## GitHub Description
**GitPuller - Learning Progress Tracker**
A Python-based tool that automates learning tracking by analyzing your GitHub commits using Google Gemini AI to extract and log new technical concepts and skills.

## Project Description (CV/Resume Style)
**GitPuller - Learning Progress Tracker**
• Developed an automated system using **Python** and **Google Gemini AI** to analyze daily GitHub commits, extracting key learning concepts and generating a structured knowledge log, streamlining the documentation of technical growth.

## Tech Stack
- **Backend:** Python, SQLAlchemy, Pydantic, GitHub API (PyGithub)
- **AI Integration:** Google Gemini (GenAI)
